Jerzy Audio Platform 0.3.0

Instalacja próbna, moduły i przywracanie systemu.

Wersja rozwojowa. Nie sprawdzono fizycznego Pi, HeadRush, Windows ani Safari. Zachowaj działającą CARD-00 i używaj osobnej kopii karty. Paczka nie spełnia jeszcze całej specyfikacji; patrz OGRANICZENIA.md.

Przed instalacją

Pi musi mieć system ARM64, glibc co najmniej 2.36, bibliotekę libstdc++ z GCC 12 lub nowszego, Python 3.9+, działający JACK2 i libjack.so.0. Windows wymaga klienta OpenSSH. Kompilacja na Pi nie jest potrzebna. Instalacja brakującego BlueZ wymaga Internetu. Brak bibliotek powoduje przerwanie stagingu, a nie pozorną instalację.

Windows

  1. Rozpakuj cały ZIP, również w ścieżce ze spacjami lub polskimi znakami.
  2. Połącz Pi i Windows z tą samą siecią. Nie trzeba zmieniać hotspotu.
  3. Kliknij START-INSTALACJA.cmd. Otworzy on PowerShell.
  4. Instalator sprawdzi bassambient.local. Jeżeli ta nazwa nie działa, wpisz IP odczytane w routerze.
  5. Przy pierwszym SSH sprawdź odcisk klucza urządzenia; hasło jerzy wpisuj wyłącznie w komunikacie OpenSSH.
  6. Instalator zweryfikuje SHA256, prześle gotowe pliki, sprawdzi architekturę, biblioteki i uruchomi testy DSP.
  7. STAGING nie wyłącza MultiFX. Dopiero wpisanie TAK rozpoczyna aktywację. Może być wymagane hasło sudo do przełączenia dotychczasowych usług systemowych.
  8. Po sukcesie pojawi się adres panelu z rzeczywistym IP i portem 8093.

Panel na iPhonie

Otwórz wyświetlony adres w Safari w tej samej sieci. W ŁAŃCUCHU wybierz Gitara lub Instrumenty i dodaj moduł. CAB wymaga wcześniejszego importu własnego WAV w Bibliotece. Instrument BassAmbient ma niezależne Bass i Ambient START/STOP, nutę podstawową, skalę, styl i tempo. W EFEKCIE dostępne są również wszystkie zaawansowane parametry i racki.

Mikser i presety

Ustaw poziomy torów, panoramę, MUTE i SOLO. Obserwuj clip przed limiterem; nie poprawiaj nadmiernego gain wyłącznie limiterem. PRESETY zapisują i odtwarzają całą sesję. Ostatnia sesja jest też zapisywana automatycznie przez panel. Zmiana grafu używa krótkiego wyciszenia, a nie bezprzerwowego przeniesienia ogonów.

Moduły offline

W Bibliotece wybierz paczkę .jamod, wpisz SHA256 od zaufanego autora i potwierdź zaufanie do jego kodu. Paczki dla innej architektury lub ABI są odrzucane. Aktualizacja zachowuje poprzednią wersję. Przed rollbackiem lub odinstalowaniem usuń instancje modułu z grafu. Zdalny katalog GitHub nie jest jeszcze dostępny.

MIDI

Podłącz wyjście MIDI do portu JerzyAudioPlatform:midi w JACK. W EFEKCIE wybierz parametr i kliknij Ucz MIDI CC, następnie porusz kontrolerem. Mapa zapisuje się w sesji. MIDI USB może wymagać istniejącego mostka ALSA–JACK; instalator nie zgaduje konfiguracji urządzenia.

System i audio

SYSTEM pozwala wybrać 44100/48000 Hz, bufor 64/128/256/512/1024 i 2/3 okresy. Usługa sprzętowa restartuje istniejący JACK, odtwarza sesję i routing. Błąd powoduje przywrócenie konfiguracji. Parametry sterownika HeadRush wymagają próby sprzętowej. Wyświetlany czas bufora nie jest pomiarem całkowitej latencji.

Bluetooth

W zakładce BLUETOOTH / MIDI wyszukaj Hotone Ampero Control i wybierz Połącz MIDI. BLE MIDI może działać bez parowania; sprawdzana jest właściwa charakterystyka GATT. Ustaw cztery przyciski przez uczenie CC/PC. Na iPhonie włącz Hotspot osobisty, sparuj z potwierdzeniem kodu i połącz PAN. Otwórz wskazany adres panelu. iPad bez Hotspotu używa Wi-Fi. Samo parowanie nie udostępnia strony WWW. Połączenie radiowe wymaga sprawdzenia na Pi.

Uruchamianie PRO

Start JAM wybiera źródło JAM i włącza generowanie. Stop JAM zatrzymuje nuty. Włączenie samej warstwy BAS nie uruchamia zatrzymanego generatora.

Przywracanie i diagnostyka

Na Windows uruchom Przywroc.ps1 przez PowerShell, aby przywrócić poprzedni MultiFX, lub Diagnostyka.ps1, aby odczytać stan. Nie kasują presetów ani sieci. Alternatywnie na Pi:

release=$(cat "$HOME/.local/share/jerzy-audio-platform/staged")
python3 "$release/deploy/raspberry-pi/control.py" rollback

Jeżeli poprzedni MultiFX jest usługą systemową, przed rollbackiem wykonaj sudo -v. Nie usuwaj katalogu danych przed odzyskaniem systemu.

Rozwiązywanie problemów

  • Brak .local: wpisz IP, nie zmieniaj Wi-Fi.
  • Brak SSH: włącz klienta OpenSSH w Windows; sprawdź SSH na Pi.
  • Nieprawidłowa architektura: wymagany system 64-bit ARM, nie ARMv7.
  • Brak bibliotek: przygotuj je przed stagingiem; paczka ich nie pobierze.
  • Nie działa JACK: sprawdź istniejący serwer i urządzenie; instalator nie uruchamia drugiego serwera.
  • Brak dźwięku: sprawdź routing fizyczny, poziomy i stan instrumentu. Otwarty panel nie dowodzi działającego toru audio.
  • XRUN: zapisz obciążenie i spróbuj większego bufora; bez pomiarów nie można obiecać ich braku.
  • Przerwany staging: ponów instalator; wcześniejsze katalogi i presety pozostają zachowane.

Autostart

Po sprawdzeniu dźwięku uruchom WLACZ-AUTOSTART.cmd. Ustawienia poprzedniego startu zostają zapisane. Szczegóły aktualizacji: NAPRAWY_0.3.0_PL.md.
